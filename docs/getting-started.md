# 導入と使い方

## 動作環境

| 項目 | 要件 |
|---|---|
| サーバーソフト | Paper 1.21.4 / 1.21.8 / 1.21.11 / 26.1.2 / 26.2 |
| Java | 1.21.4 / 1.21.8 / 1.21.11 は 21 以降、26.1.2 / 26.2 は 25 以降 |

26.x は対応済みです。Java 25でのサーバー起動とプラグイン有効化を確認しています。Mineflayer のプロトコル未対応によりゲームプレイ E2E の完走確認は未完了ですが、これはプラグイン本体の未対応を示すものではありません。

## インストール

1. [Releases](https://github.com/sakaneji/StorageSign-Refactored/releases) から `.jar` を取得します。
2. サーバーの `plugins/` に配置します。
3. サーバー起動後に `plugins/StorageSign-Refactored/config.yml` が生成されます。

外部 Logger を使う場合は `teruteru128/logger` のプラグインも `plugins/` に配置します。Logger がなくても起動します。

## Craft

デフォルトのクラフトレシピは次の通りです。

```text
[チェスト]       [チェスト]         [チェスト]
[チェスト]       [看板]             [チェスト]
[チェスト]       [チェスト]         [チェスト]
```

`config.yml` の `hardrecipe: true` で下段中央がエンダーチェストになります。

## 基本操作

- StorageSign の右クリック操作はメインハンド基準です。
- オフハンド操作は、スニーク中の誤設置防止を除いて無視されます。
- スペクテーターモードでは操作できません。

### 設置

1. StorageSign アイテムを手に持ちます。
2. 看板として設置します。
3. 空の StorageSign なら、登録したいアイテムを持って看板を右クリックして登録します。
4. 以後、隣接コンテナに対する自動入出庫が機能します。

通常看板へ直接 `StorageSign` と手入力して作成できるのはクリエイティブモードだけです。

### 手動インポート

- 登録されたアイテムを持って右クリックすると、インベントリ内の合致アイテムを格納します。
- スニーク + 右クリックで、手持ちスロットのアイテムのみ格納します。
- 同じ内容の StorageSign アイテムを右クリックすると、看板 1 枚単位で内容をマージします。

### 手動エクスポート

- 空手、または登録内容と異なるアイテムで右クリックすると、可能な範囲で 1 スタック分をドロップします。
- スニーク + 右クリックで 1 個だけドロップします。
- 染料やインクで右クリックした場合は、搬出よりも Vanilla の看板色変更・発光変更を優先します。

### 分割

登録済み StorageSign ブロックを、空 StorageSign アイテムで右クリックすると、内容を手持ちの空 StorageSign へ均等分割します。

- `B` を保管数、`N` を空 StorageSign 数とすると、各アイテムは `floor(B / (N + 1))` 個を受け取ります。
- `divide-limit` と `sneak-divide-limit` が上限です。
- `manual-export: false` かつ保管数が空 StorageSign 数以下なら分割しません。
- StorageSign アイテム自身を保管しているブロックでは、空 StorageSign は sign-in-sign の手動インポートとして扱います。

保管数量の上限は `Integer.MAX_VALUE` です。上限到達時は空き容量分だけを受け入れます。

## ItemMeta

保管できるのは、識別子から完全に復元できる ItemMeta だけです。カスタム名、Lore、独自 Enchant、複数エンチャント本、カスタム効果付き Potion、中身入りシュルカーボックス、蜂入りの蜂の巣/養蜂箱、効果付き花火などは拒否します。

不吉な旗の Bukkit API 構築に失敗した場合は白旗へ変換せず、数量も変更しません。復旧するまで搬出は停止し、再試行します。
